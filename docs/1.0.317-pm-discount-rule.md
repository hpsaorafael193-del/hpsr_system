# HPSR v1.0.317 — regra de desconto PM

- Corrige o preço-base do Kit Médico para R$ 2.000.
- Substitui percentuais PM por desconto monetário histórico por item.
- Kit Médico: desconto de R$ 500, portanto R$ 2.000 → R$ 1.500 para PM.
- Atadura: desconto de R$ 100, portanto R$ 300 → R$ 200 para PM.
- Adrenalina: desconto de R$ 1.000, portanto R$ 8.000 → R$ 7.000 para PM.
- O preço PM é calculado a partir do preço-base atual menos o desconto histórico; não há preço PM fixo duplicado.
- Mantém Tratamento em R$ 2.000.
- Sem alteração no Supabase.
