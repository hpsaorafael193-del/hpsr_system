# HPSR v1.0.323 — Simplificação do editor de exames

- Remove o vínculo de exames com consultas do editor de Exames.
- Novos exames são salvos diretamente no prontuário como registros de exame, sem `appointmentId` gerado pelo editor.
- Registros históricos que já possuem referência de consulta são preservados e não são apagados.
- Remove a etapa visual “Contexto” da barra lateral.
- Remove a opção “Contexto clínico” do editor inteligente.
- O motor adaptativo deixa de usar contexto clínico na geração de novos laudos; permanece focado em exame, perfil de resultado, adaptadores técnicos e variáveis efetivamente relevantes.
- Fluxo lateral simplificado para 3 etapas: Identificação → Exame → Finalização.
- Sem alteração de banco de dados.
