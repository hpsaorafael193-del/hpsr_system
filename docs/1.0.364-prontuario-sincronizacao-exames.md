# v1.0.364 — Sincronização de exames no Prontuário

- O cache do Prontuário passa a ser apenas uma camada de renderização imediata.
- Mesmo com cache recente, a tela sempre sincroniza `patient_registry`, `clinical_records`, consultas, Portal e vínculos com o Supabase.
- Chave do cache atualizada para `hpsr-prontuario-session-cache-v3`, invalidando estados antigos incompletos.
- O Histórico de Exames/Documentos agora usa comparação case-insensitive de `record_type`, trata erros de leitura explicitamente e não transforma falha do Supabase em “Nenhum registro salvo”.
- O botão de exclusão no histórico respeita as mesmas permissões administrativas da proteção aplicada no banco.
- Nenhuma migration nova foi necessária.
