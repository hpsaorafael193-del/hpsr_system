# v1.0.357 — Relatórios sem espaço vazio no cabeçalho

## Correção

- Corrigido o crescimento vertical indevido da seção **Central de relatórios**.
- A regra global de layout aplicava `flex: 1` ao último `section` direto da página, fazendo o cabeçalho ocupar todo o espaço livre depois que os KPIs foram compactados.
- A seção agora usa altura natural (`flex-none`) e mantém apenas o espaço necessário para título, filtros e navegação **Visão geral / Atividades / Ponto**.
- Os quatro KPIs compactos permanecem logo abaixo da navegação, sem faixa vazia entre os dois blocos.
- Nenhuma regra de relatório, filtro, exportação ou banco de dados foi alterada.
