# Versão 1.0.173 — Triagem de tratamento e uso de kit médico

## Objetivo
Adicionar ao questionário do Banco de Sangue uma verificação de tratamento recente ou uso de kit médico, bandagem ou analgésico.

## Arquivos alterados
- `src/app/dashboard/banco-de-sangue/page.tsx`
- `src/components/layout/DeveloperCreditsModal.tsx`
- `package.json`
- `package-lock.json`

## Alterações realizadas
- Adicionada a pergunta: `Realizou algum tratamento ou utilizou kit médico, bandagem ou analgésico recentemente?`.
- Resposta `Sim` classifica automaticamente o doador como `Inapto temporário`.
- O motivo é registrado na análise automática da ficha.

## Compatibilidade
- Registros antigos foram preservados.
- Fichas anteriores sem o novo campo continuam válidas e não são reclassificadas.

## Migrações
- Nenhuma. O questionário é armazenado no `payload` já existente de `blood_donations`.

## Otimizações
- Nenhuma consulta nova ao Supabase.
- Nenhuma nova tabela ou coluna.

## Validações
- Revisão estática do fluxo de formulário e análise automática.
- Arquivos JSON validados.
- Build completo não executado no ambiente por ausência das dependências instaladas.
