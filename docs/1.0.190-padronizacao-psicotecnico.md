# Versão 1.0.190 — Padronização do psicotécnico

## Objetivo
Padronizar somente os contextos e os perfis de resultado já utilizados pelo modelo existente de Avaliação Psicotécnica, sem alterar sua estrutura, seções ou disposição.

## Alterações
- Contextos disponíveis:
  - Porte de arma
  - Pilotagem aérea
  - Rotineiro
- Resultados disponíveis:
  - Apto
  - Apto com ressalvas
  - Não apto
  - Inconclusivo
- O resultado padrão passou a ser `Apto`.
- Os quatro perfis receberam achados predeterminados coerentes com os campos já existentes no modelo, incluindo dados psicológicos, físicos, cardíacos e respiratórios.
- Mantidas integralmente as oito seções atuais do laudo psicotécnico.
- Mantidos os campos e parâmetros já existentes; nenhum novo campo foi criado.

## Compatibilidade
- Os identificadores dos novos perfis são compatíveis com os anexos visuais existentes do psicotécnico.
- Nenhuma alteração em banco de dados ou migração foi necessária.

## Validação
- Revisão estática da estrutura TypeScript e dos identificadores dos parâmetros.
- Conferência de que todos os resultados predeterminados correspondem a parâmetros existentes no modelo.
