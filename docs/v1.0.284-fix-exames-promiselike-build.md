# v1.0.284 — Correção de tipagem no vínculo manual de exames

Corrige o carregamento das consultas relacionadas em `Prontuários > Exames`. O cliente do Supabase retorna um `PromiseLike`, que não expõe `.finally()` na tipagem usada pelo projeto.

O fluxo foi reescrito com `async/await` e `try/finally`, mantendo exatamente a mesma consulta, filtros, estados e comportamento funcional.

Nenhuma regra de vínculo médico-paciente, agenda clínica, planejamento ou prontuário foi alterada.

O aviso do ESLint sobre `es-to-primitive/es2015` é de instalação local de dependências: o pacote já consta no lockfile transitivo. Em instalação inconsistente, reinstalar dependências com pnpm corrige o carregamento do plugin.
