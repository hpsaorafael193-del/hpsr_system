# HPSR v1.0.313 — Organização visual de solicitações

## Alterações

- Solicitações de consulta passam a ser exibidas em blocos visuais independentes por especialidade.
- Cada especialidade possui cabeçalho destacado e contador próprio de solicitações.
- Cards de solicitações receberam maior espaçamento, destaque lateral, sombra leve e hierarquia visual mais clara.
- Meus aceites mantém a separação entre Para contato e Histórico de aceites, com grupos de especialidade visualmente mais fortes.
- Cards de aceites também receberam destaque visual sem alterar o fluxo ou status clínico.
- Ordenação continua priorizando especialidade e registros mais recentes dentro de cada área.

## Banco de dados

Nenhuma alteração no Supabase foi necessária. Esta versão é exclusivamente de organização e apresentação da interface.
