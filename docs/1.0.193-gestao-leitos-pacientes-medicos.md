# Versão 1.0.193 — Seletores da Gestão de Leitos

## Objetivo
Conectar os seletores de paciente e médico responsável da Gestão de Leitos às fontes reais já existentes no sistema.

## Alterações
- Removidas as listas estáticas vazias de pacientes e médicos.
- O seletor de pacientes reutiliza a lista centralizada do Prontuário por meio de `PatientSelectionProvider`.
- O cadastro rápido de paciente passa a usar a mesma RPC segura do Prontuário, exigindo nome e passaporte.
- O seletor de médico carrega somente profissionais clínicos aprovados da tabela `profiles`.
- Os nomes dos responsáveis são exibidos no padrão `Dr. Nome`.
- Adicionados estados de carregamento e busca nos dois seletores.

## Reutilização
- `PatientSelectionProvider` para pacientes e sincronização.
- `isClinicalProfessional` para identificar profissionais clínicos.
- `StyledSelect` existente, sem alteração visual estrutural.

## Banco e desempenho
- Nenhuma migração.
- A lista de pacientes reutiliza o carregamento global já existente.
- A lista de médicos faz uma única consulta ao abrir a página.
- Nenhum polling ou consulta recorrente foi adicionado.

## Validação
- Arquivo TSX validado pelo parser TypeScript sem erro de sintaxe.
- Build completo não executado neste ambiente porque o pacote limpo não contém dependências instaladas.
