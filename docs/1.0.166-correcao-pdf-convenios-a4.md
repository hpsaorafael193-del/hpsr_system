# Versão 1.0.166 — Correção do PDF mensal de convênios

## Objetivo
Garantir que o relatório mensal de convênios seja impresso integralmente dentro da área útil de uma folha A4, sem cortes laterais.

## Arquivo alterado
- `src/app/dashboard/convenios/page.tsx`

## Ajustes
- Página A4 em orientação retrato com margens de 12 mm.
- Conteúdo limitado à largura útil da folha.
- Tabelas com layout fixo e colunas proporcionais.
- Quebra automática de textos longos.
- Fonte e espaçamentos compactados apenas no relatório impresso.
- Cabeçalhos de tabela repetidos em novas páginas.
- Linhas protegidas contra quebra no meio.
- Visualização em tela separada do layout de impressão.

## Banco e compatibilidade
- Nenhuma migração.
- Nenhuma consulta nova ao Supabase.
- Nenhuma regra de convênios alterada.

## Validações
- Estrutura HTML/CSS da impressão revisada.
- Versões atualizadas para 1.0.166.
- Build completo não executado porque o pacote de trabalho não contém as dependências instaladas.
