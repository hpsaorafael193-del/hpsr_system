# HPSR 1.0.259 — Portal do Paciente mais intuitivo

- Página pública simplificada: mantém apenas apresentação curta e acesso ao Portal.
- Informações de valores deixam de aparecer publicamente e passam para o fluxo de Solicitar consulta.
- Botão flutuante **Como usar** disponível no Portal, com ajuda curta para cada função.
- Tela inicial autenticada funciona como um painel leve com atalhos e descrições simples.
- Textos de consulta, exame, acompanhamento e prontuário foram simplificados para linguagem comum.
- Agendamento continua sem escolha de data/horário pelo paciente.
- O médico pode combinar o atendimento pelo Discord ou dentro do RP, conforme sua preferência.
- Quando o sistema exigir ID do Discord, ele continua sendo validado como ID numérico de apoio.
- Nenhuma migration foi necessária.
