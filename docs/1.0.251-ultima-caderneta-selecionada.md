# HPSR System 1.0.251 — Vacinação: abrir última caderneta utilizada

## Regra
- Ao selecionar um paciente com histórico vacinal, a aba abre automaticamente a caderneta correspondente à aplicação mais recente.
- Quando a última aplicação for do grupo Adulto, também é restaurado o modelo masculino/feminino salvo naquela aplicação.
- Se o paciente ainda não possuir nenhuma vacina registrada, o fallback inicial é Adulto Masculino.
- A seleção manual continua disponível normalmente.

## Persistência
A regra reutiliza `clinical_records` (`record_type = Vacina`) e os campos `vaccine.group` / `vaccine.adultVariant` já existentes no payload.

## Migration
Nenhuma.
