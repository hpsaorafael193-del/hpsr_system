# v1.0.283 — Correção de build da Agenda Clínica

Correção pontual de sintaxe em `src/app/dashboard/agendamento/clinica/page.tsx`.

Ao remover o card administrativo de vínculos da Agenda Clínica na v1.0.282, permaneceu um bloco JSX condicional vazio (`{isDeveloper && (...)}`), o que fazia o parser do Next.js interromper o build antes do `return` principal.

A v1.0.283 remove apenas esse bloco residual. Nenhuma regra de agenda, prontuário, vínculo médico-paciente, publicação de horários ou planejamento clínico foi alterada.
