# Versão 1.0.203 — Relatório histórico completo e otimização

## Alterações
- Promoções passam a ser consolidadas a partir das atividades do sistema e do histórico salvo em `team_members.payload.history`.
- Mudanças de cargo registradas como “Cargo alterado de ... para ...” também entram na aba Promoções.
- Registros são deduplicados por profissional, data, cargos e descrição.
- Mantida a captura integral das tabelas já utilizadas pelo relatório, inclusive registros antigos.
- A compactação do XLSX foi reduzida para nível 1, diminuindo o tempo até abrir a janela de salvamento.
- Paginações longas cedem brevemente o controle ao navegador para evitar travamento visual.

## Migrações
- Nenhuma.

## Compatibilidade
- Nenhum dado existente foi alterado ou excluído.
