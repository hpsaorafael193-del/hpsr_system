# HPSR 1.0.269 — Confirmação visual de salvamento

## Objetivo
Dar retorno imediato e discreto depois que registros clínicos forem realmente persistidos no sistema.

## Alterações
- Adicionado toast global de sucesso, sem bloquear a tela e com fechamento automático.
- Exames exibem confirmação somente após inserção bem-sucedida em `clinical_records`.
- Documentos substituem o modal de sucesso por aviso pequeno não bloqueante.
- Vacinação exibe confirmação após registro e atualização do histórico.
- Registros clínicos criados pelo Prontuário também exibem confirmação.
- Falhas continuam usando os avisos de erro existentes.

## Banco de dados
Nenhuma migration necessária.
