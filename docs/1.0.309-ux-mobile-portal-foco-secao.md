# v1.0.309 — UX mobile do Portal do Paciente

- Navegação entre funções do portal agora reposiciona automaticamente a tela no início da área aberta.
- Aplicado aos cards da página inicial, navegação superior, Meus dados, aviso de novos horários e atalhos internos entre áreas.
- O conteúdo aberto recebe foco programático para reforçar a mudança de contexto e melhorar acessibilidade.
- Rolagem suave é usada por padrão; `prefers-reduced-motion` é respeitado e desativa a animação.
- Nenhuma regra clínica, dado, API ou estrutura do Supabase foi alterada.
