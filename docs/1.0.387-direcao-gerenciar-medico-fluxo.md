# HPSR System 1.0.387 — Gerenciar médico com fluxo corrigido

## Objetivo

Corrigir a reorganização da aba Direção sem redesenhar a interface de edição de médicos.

## Alterações

- O botão **Gerenciar médico** volta a abrir diretamente o editor de médico que já existia antes da refatoração da 1.0.386.
- O conteúdo, os campos, a organização e o comportamento do editor original foram preservados.
- O editor ganhou apenas um acesso secundário **Solicitações** no cabeçalho, mantendo a edição como conteúdo principal do fluxo.
- **Solicitações de médicos** usa o fluxo anterior de análise de pedidos de acesso/cadastro.
- O histórico dessas solicitações continua dentro do próprio modal por meio de **Mostrar histórico**, evitando um novo botão externo na Direção.
- Dentro de Solicitações, **Voltar ao gerenciar médico** retorna ao editor principal.
- O agrupamento de **Formulários pendentes + Histórico de formulários** implementado na 1.0.386 foi mantido.
- O botão externo redundante de Histórico de formulários continua removido.

## Banco de dados

Nenhuma alteração de banco ou migration nesta versão.
