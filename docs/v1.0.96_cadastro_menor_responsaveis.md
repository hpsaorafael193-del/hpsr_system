# Versão 1.0.96 — Cadastro de menores e responsáveis

- O Portal do Paciente identifica cadastros com idade inferior a 18 anos.
- Para menores, passa a ser obrigatório informar ao menos um passaporte de responsável.
- Cada responsável é validado diretamente no cadastro institucional `patient_registry`.
- O responsável não precisa possuir conta no portal nem estar autenticado para validar o cadastro do menor.
- O cadastro é bloqueado quando algum responsável informado não existe no prontuário.
- Após a criação da conta, os vínculos são registrados em `patient_guardian_links` como autorizados.
