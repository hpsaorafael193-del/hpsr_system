# HPSR System v1.1.16-test.21 — fluxo prático do Acompanhamento

## Objetivo
Refinar a navegação e a distribuição interna da aba Acompanhamento sem retornar ao layout principal em duas colunas.

## Alterações

- A página permanece em listagem vertical total.
- `Planejamento ativo` passa a listar todos os planejamentos que o perfil atual pode gerenciar, com modalidade e data no rótulo.
- A Definição médica sinaliza de forma direta se o usuário está criando um novo planejamento ou editando um registro salvo.
- Campos internos receberam limites de largura menores e proporcionais ao tipo de dado.
- Datas foram compactadas e os controles de sugestão/confirmação do cronograma ficam na mesma faixa funcional.
- Observações gerais usam largura controlada.
- Metadados de cada consulta/etapa e o texto de Planejamento previsto usam largura confortável sem ocupar toda a tela.
- O Histórico agora funciona como arquivo completo e possui busca por paciente, passaporte, data ou modalidade.
- Filtros rápidos do Histórico: `Todos`, `Gestacional` e `FIV`, respeitando as modalidades que o perfil pode gerenciar.
- O planejamento atualmente carregado recebe indicação `Em edição` também no Histórico.

## Regras preservadas

- Clique em uma linha do Histórico carrega o planejamento na área superior.
- `Editar consultas` continua abrindo o modal individual.
- Não existe botão redundante `Editar integral`.
- Salvar continua separado de liberar para a paciente.
- PNG continua sendo materializado somente sob solicitação explícita de download.
- Nenhuma alteração de schema ou migration foi necessária.

## Validação

- 27/27 scripts de regressão aprovados.
- `portal-audit.mjs`: sintaxe de 238 arquivos TS/TSX e CSS aprovada.
- O runtime disponível nesta sessão permanece em Node 22.16.0 e sem `pnpm`.
- `pnpm install`, `pnpm run typecheck` e `pnpm run build` foram tentados, mas não executaram porque `pnpm` não está disponível no runtime.
