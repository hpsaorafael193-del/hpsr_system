# Regras visuais fixas do ambiente HPSR

Estas regras são obrigatórias para todas as abas do dashboard e devem ser preservadas em novas telas e reformulações.

1. Toda aba deve manter a barrinha fina e escura no topo, usando o padrão existente `hpsr-topbar` / `PageHeader`.
2. O conteúdo principal deve ficar diretamente sobre o fundo da página. Não criar um card, container arredondado ou painel decorativo envolvendo toda a aba.
3. Evitar “área dentro de área”: cada função deve ter, no máximo, uma superfície principal. Dentro dela, preferir divisores, linhas, espaçamento e hierarquia tipográfica em vez de novos cards aninhados.
4. Cards e caixas só devem existir quando representam uma função ou agrupamento real. Não usar containers apenas para decorar ou para envolver outros containers.
5. Ao adaptar uma aba, reutilizar o padrão estrutural das abas já aprovadas antes de criar novos invólucros visuais.
