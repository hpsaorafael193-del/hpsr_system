# HPSR System 1.0.377 — editor e histórico compactos

- O editor de exames passa a ter altura visual controlada e rolagem interna, evitando que espaços/Enters aumentem indefinidamente a altura da página.
- As guias e a contagem de páginas continuam indicando quando o laudo ultrapassa a primeira página.
- Informações do exame recolhem automaticamente após a seleção do exame e aplicação do modelo, permanecendo disponíveis em resumo com ação para editar.
- Histórico de exames/documentos foi compactado: título, paciente, data, visibilidade e ações essenciais ocupam menos altura.
- Nenhuma alteração de banco foi necessária.
