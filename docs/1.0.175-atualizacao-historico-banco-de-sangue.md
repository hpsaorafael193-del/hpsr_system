# Versão 1.0.175 — Atualização de fichas no histórico do Banco de Sangue

## Objetivo
Permitir a atualização de uma ficha já registrada diretamente pelo histórico do Banco de Sangue.

## Arquivos alterados
- `src/app/dashboard/banco-de-sangue/page.tsx`
- `src/components/layout/DeveloperCreditsModal.tsx`
- `package.json`
- `package-lock.json`

## Estruturas reutilizadas
- Formulário existente da triagem.
- Análise automática existente.
- Tabela `blood_donations` e o campo `payload` já utilizados pelo módulo.

## Alterações realizadas
- Adicionado botão `Atualizar` em cada ficha do histórico.
- Ao atualizar, os dados da ficha são carregados no formulário atual.
- O botão principal muda para `Atualizar ficha`.
- A operação atualiza o mesmo registro no banco, sem criar duplicata.
- A data original do registro é preservada.
- A opção `Cancelar edição` restaura uma nova triagem.

## Migrações
- Nenhuma.

## Otimizações
- Nenhuma consulta adicional ao Supabase.
- A atualização utiliza um único `UPDATE` filtrado pelo `id` da ficha.

## Validações
- Revisão estática do fluxo de criação, edição e exclusão.
- Conferência de que o histórico é atualizado em memória após confirmação do banco.
- Build completo não executado no ambiente por ausência das dependências instaladas.
