# v1.1.16-test.12 — Editor individual em modal

## Objetivo
Separar o histórico de planejamentos da edição das consultas individuais.

## Fluxo
- O Histórico de planejamentos permanece como lista de registros salvos.
- Cada planejamento possui o botão **Editar consultas**.
- O botão abre um modal exclusivo daquele planejamento.
- As consultas/etapas mantêm o visual simples anterior.
- A seleção de uma consulta abre os campos individuais dentro do modal.
- O planejamento integral continua sendo editado pela área principal, via **Editar integral**.

## Salvamento individual
- **Salvar consulta/etapa** persiste somente a consulta selecionada.
- O campo Planejamento previsto continua sincronizado com a linha correspondente do integral.
- Evolução, exames, resultados, observações compartilháveis e campos internos permanecem individuais.
- Salvar não libera automaticamente para a paciente.
- Prévia/liberação continuam independentes.
- Nenhum PNG é criado pelo salvamento; PNG continua somente sob pedido explícito de download.

## Proteção contra perda de alterações
Ao fechar o modal ou trocar de consulta com conteúdo não salvo, o sistema oferece:
- Salvar e continuar
- Descartar
- Cancelar

## Banco
Nenhuma migration e nenhuma mudança de schema nesta versão.
