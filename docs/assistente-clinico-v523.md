# v0.5.23 — Primeira versão do Assistente Clínico

- Módulo de Obstetrícia com cálculo gestacional e planejamentos curto/longo.
- Módulo de Ginecologia com planejamento de fertilização em cinco semanas.
- Módulo de Pediatria com cálculo matemático de dose, concentração e volume.
- Simulador persistente de especialidade para testes, sem alterar o perfil real.
- Seleção de pacientes pelo cadastro institucional existente.
- Nenhum resultado é salvo automaticamente no prontuário nesta etapa.
