# HPSR System 1.0.383 — Correção do fluxo vertical de Exames

- Corrige a composição introduzida na 1.0.382 que colocou Informações do exame e Catálogo lado a lado.
- Restaura o fluxo vertical definido para a página: Informações → Catálogo → Editor → Histórico.
- Mantém paciente e médico responsável um abaixo do outro.
- Mantém as melhorias da 1.0.382: cabeçalho simplificado, contexto recolhido após seleção, anexos integrados ao editor e configuração do modelo responsiva.
- Nenhuma alteração de banco, regra clínica ou persistência.
