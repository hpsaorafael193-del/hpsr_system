# HPSR System 1.0.230 — Alinhamento de dados das cadernetas

## Objetivo
Corrigir o posicionamento dos dados de identificação em todos os modelos de caderneta de vacinação, preservando integralmente as artes existentes.

## Arquivos alterados
- `src/lib/vaccination.ts`
- `src/app/dashboard/vacinacao/page.tsx`
- `src/components/layout/DeveloperCreditsModal.tsx`
- `package.json`
- `package-lock.json`

## Estruturas reaproveitadas
- Templates PNG existentes de Adulto masculino, Adulto feminino, Criança, Gestante e Idoso.
- Renderizador Canvas único usado por prévia e PNG final.
- `getVaccinationCardDefinition` como fonte central de configuração de cada modelo.

## Alterações realizadas
- Cada template passou a possuir seu próprio mapa de campos de identificação.
- Campos sobre linhas usam início e fim da linha útil, posicionando o conteúdo somente depois do rótulo impresso.
- O texto é apoiado harmonicamente sobre a linha e reduz automaticamente o tamanho da fonte quando necessário para não ultrapassar a área disponível.
- A caderneta infantil, que não possui linhas horizontais nesses campos, usa áreas úteis próprias após os rótulos.
- Removidas coordenadas de identificação espalhadas em condicionais do renderizador; a posição agora vem da definição do modelo.
- Nenhuma arte/template foi redesenhada ou gerada.

## Migrations
- Nenhuma.

## Compatibilidade
- Nenhuma alteração de schema, dados persistidos, RLS ou RPC.
- Registros antigos de vacinação permanecem compatíveis.
- Prévia e PNG final continuam usando exatamente o mesmo renderizador e mapa de coordenadas.

## Validação
- Revisão estática dos cinco templates existentes e das áreas de identificação de cada um.
- Revisão estática do renderizador e dos mapas de coordenadas.
- `npm run build` foi executado, mas não iniciou a compilação porque o ambiente não possui as dependências instaladas (`next: not found`). Portanto, build não foi declarado como aprovado.
