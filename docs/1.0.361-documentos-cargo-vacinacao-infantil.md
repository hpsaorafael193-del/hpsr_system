# v1.0.361 — Documentos, Vice Diretor / Dev e vacinação infantil

## Documentos

- O editor `contentEditable` deixa de receber `dangerouslySetInnerHTML` em toda renderização.
- Digitar, apagar, usar espaço, Enter ou editar no meio do texto não reconstrói mais o DOM do editor nem reposiciona o cursor no início.
- O HTML continua sincronizado para rascunho local, pré-visualização e exportação.
- Troca/aplicação de modelo, limpeza e ferramentas de formatação continuam atualizando o editor de forma explícita.
- Os nove modelos institucionais foram revistos com textos mais completos e melhor contextualização, sem inventar informações clínicas não fornecidas.

## Cargo e administração do sistema

- O cargo `Diretor Técnico / Dev` foi descontinuado.
- A identidade administrativa atual usa o cargo hospitalar `Vice Diretor / Dev`.
- A função técnica fica separada como `Administrador do Sistema`, armazenada em `profiles.staff_metadata.systemRole`, com `accessLevel = Total`.
- `system_owner_identity` continua sendo a fonte da identidade administrativa exclusiva.
- `is_hpsr_system_admin()` desacopla as permissões administrativas do nome do cargo hospitalar.
- O perfil administrativo mantém acesso total, gestão global de agenda, vínculos internos e demais funções administrativas existentes.
- `Vice Diretor / Dev` é exclusivo da identidade administrativa configurada e não pode ser solicitado pelo fluxo público de cadastro.

## Vacinação infantil

- A caderneta infantil passou a usar o template `caderneta-crianca-moderna.png`, preservando a estrutura e os campos do cartão atual.
- O novo modelo recebe cores suaves adicionais, moldura multicolorida, áreas de aplicação em tons alternados e elementos lúdicos discretos.
- Os carimbos das vacinações infantis ficaram maiores e usam cores alternadas para facilitar a leitura visual.
- Adulto, gestante e idoso permanecem sem alteração visual.
