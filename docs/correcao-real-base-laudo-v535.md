# v0.5.35 — Correção real da base visual dos laudos

- O gerador de PNG deixou de desenhar o arquivo de fundo antigo antes do novo cabeçalho.
- O cabeçalho, linhas institucionais e marca d’água agora são desenhados diretamente no canvas.
- Foram eliminadas as sobreposições causadas pelo logotipo e pelos textos incorporados à imagem antiga.
- A identificação, data, protocolo, título e conteúdo passam a usar uma única grade de alinhamento.
- O nome do paciente permanece no nome do arquivo PNG exportado.
