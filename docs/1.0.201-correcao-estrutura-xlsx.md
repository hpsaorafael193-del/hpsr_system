# Versão 1.0.201 — Correção estrutural do relatório XLSX

## Problema
O arquivo era baixado, mas o Microsoft Excel detectava conteúdo inválido e tentava reparar a pasta de trabalho.

## Causa
No XML de cada planilha, o elemento `mergeCells` era emitido antes de `autoFilter`. Essa ordem não segue a sequência exigida pelo schema Open XML, embora leitores mais tolerantes consigam interpretar o arquivo.

## Correção
- `autoFilter` agora é emitido antes de `mergeCells`.
- Mantida a compactação DEFLATE via JSZip.
- Mantida a sanitização de textos e caracteres XML.
- Nenhuma alteração nas informações ou abas do relatório.

## Migrações
Nenhuma.

## Validação
- Revisão da sequência dos elementos conforme a estrutura Open XML de worksheet.
- Pacote ZIP do projeto validado.
