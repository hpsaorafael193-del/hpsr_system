# Versão 1.0.102 — Correção da exportação PNG de exames

- Imagens externas usadas na composição do exame agora são carregadas com CORS anônimo antes de serem desenhadas no canvas.
- URLs remotas que não autorizam leitura deixam de contaminar o canvas e são ignoradas de forma segura.
- A normalização da assinatura passou a tratar `SecurityError` no `getImageData` sem interromper a geração do exame.
- O PNG continua sendo gerado mesmo quando uma assinatura externa não permite processamento pelo navegador.
