# HPSR v1.0.315 — descontos percentuais da PM

## Alteração

A calculadora deixou de depender de preços PM fixos para os itens que historicamente possuíam desconto especial.

Os percentuais preservados são:

- Kit médico: 33,33% (1/3)
- Atadura: 50%
- Adrenalina: 12,5%

O preço PM passa a ser calculado dinamicamente sobre o preço-base atual do item, com arredondamento para centavos. Itens sem desconto PM histórico continuam usando o valor normal.

## Valores atuais resultantes

- Kit médico: R$ 2.000,00 → R$ 1.333,33
- Atadura: R$ 300,00 → R$ 150,00
- Adrenalina: R$ 8.000,00 → R$ 7.000,00

Nenhuma alteração no Supabase.

## Ajuste adicional de item

- `TRATAMENTO NORTE` foi renomeado para `TRATAMENTO`.
- Valor atualizado de R$ 1.500 para R$ 2.000.
- Removida a referência específica à região Norte na descrição.
