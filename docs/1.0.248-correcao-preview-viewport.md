# HPSR System 1.0.248 — Correção da preview adaptativa de vacinação

## Correção
- Corrigido `ReferenceError: previewViewportRef is not defined`.
- Adicionadas as declarações de `previewViewportRef` e `previewViewport`.
- Adicionado `ResizeObserver` para medir a área útil real da pré-visualização.
- `getPreviewMetrics` passa a receber corretamente as dimensões medidas da área disponível.
- Mantida a lógica da v1.0.247 de fazer a caderneta preencher o maior espaço possível sem aumentar a altura geral da página.

## Migration
- Nenhuma.
