# v1.0.355 — download de exame em PNG no Prontuário

## Correção

O visualizador de exames do Prontuário utilizava as prévias PNG já salvas no registro, mas no momento do download reconstruía uma página HTML e forçava a extensão `.html`.

A partir desta versão:

- exames com uma página são baixados diretamente como `.png`;
- exames com várias páginas baixam cada página como um PNG separado (`_pagina_1`, `_pagina_2`, etc.);
- o botão passa a indicar `Baixar PNG` ou `Baixar PNGs` quando as imagens estão disponíveis;
- exames legados sem prévia PNG não são mais baixados silenciosamente como HTML: o sistema informa que aquele registro antigo não possui PNG salvo;
- documentos continuam com fallback HTML apenas quando não possuem prévia em imagem.

Não houve alteração no banco de dados.
