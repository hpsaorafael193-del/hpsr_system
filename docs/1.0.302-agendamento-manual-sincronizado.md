# v1.0.302 — Agendamento manual sincronizado

- Aceitar uma solicitação continua sendo somente a assunção do caso para contato com o paciente.
- O aceite não cria data, horário ou consulta automaticamente.
- O agendamento permanece exclusivamente manual pela Agenda Clínica.
- Ao salvar manualmente um agendamento para uma solicitação aceita do mesmo paciente, especialidade e médico, o registro aceito é reutilizado e passa a `Agendada`, preservando o histórico do aceite e evitando duplicidade.
- No Agendamento Geral, solicitações apenas aceitas passam a exibir `Aguardando agendamento` / `Definição manual`, em vez de sugerir que já existe uma consulta.
- Depois do agendamento manual, a visão geral mostra a data e o horário reais.
