# 1.1.16-test.173 — rotas e funções das abas

A página compartilhada passa a usar /dashboard/acompanhamento. Gestação, FIV, Pediatria e suas vacinações continuam alternando dentro dessa mesma página. Foram atualizados os menus desktop e mobile, os atalhos dos pacientes, os links de modalidade e a regra da barra institucional.

A aba Relatórios estava na rota /dashboard/direcao. Sua implementação e seu endereço agora são /dashboard/relatorios. O menu também passa a usar o nome plural Relatórios.

Os endereços antigos /dashboard/obstetra, /dashboard/obstetra/pediatria, /dashboard/obstetricia e /dashboard/direcao redirecionam diretamente para os destinos correspondentes. Parâmetros de paciente, modalidade, vacinação e filtros são preservados. O redirecionamento legado de Obstetrícia para o antigo assistente clínico foi corrigido.

Direção/equipe é uma diferença de abrangência: a aba gerencia a equipe, portanto o endereço continua compatível com a função. Agenda do Médico/clinica identifica a agenda clínica; também permanece funcionalmente compatível. Traumatologia atualmente é mais específica no conteúdo, dedicado ao controle de gesso. Esses nomes não foram alterados nesta revisão.

O endereço legado /dashboard/assistente-clinico já é apenas um redirecionamento para o início; não há assistente clínico ativo nessa página.

Não houve alteração de banco de dados, registros clínicos, permissões ou snapshots.
