# Versão 1.0.125 — download multipágina em PNG

- Exames com uma página continuam sendo baixados diretamente em PNG.
- Exames com várias páginas passam a disparar um download PNG por página.
- Antes do processo, o Portal do Paciente informa que o navegador poderá solicitar permissão para múltiplos downloads.
- O paciente precisa confirmar a ação no sistema e permitir múltiplos downloads no navegador.
- Não são utilizados PDF, ZIP ou arquivo HTML intermediário.
