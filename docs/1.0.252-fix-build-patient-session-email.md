# HPSR System 1.0.252 — Correção de build na sessão do paciente

## Correção
A rota `src/app/api/paciente/sessao/route.ts` utilizava `access.email`, porém a consulta em `patient_portal_access` não selecionava a coluna `email`.

A consulta foi corrigida de:
`patient_passport,access_enabled`

para:
`patient_passport,email,access_enabled`

A coluna `email` já existe na estrutura persistente de `patient_portal_access`; nenhuma migration foi necessária.

## Escopo
- Correção técnica objetiva de tipagem/build.
- Nenhuma alteração de regra de negócio ou interface.
- Nenhuma migration.
