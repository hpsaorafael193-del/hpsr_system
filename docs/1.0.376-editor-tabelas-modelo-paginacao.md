# HPSR System 1.0.376 — tabelas, modelo e paginação

- Tabelas inseridas manualmente passam a usar o mesmo componente visual das tabelas geradas pelos modelos de exames.
- O controle **Usar modelo** virou um switch compacto: ligado em verde exibe as opções do modelo; desligado recolhe o painel sem apagar o conteúdo já aplicado ao editor.
- O editor exibe a quantidade estimada de páginas e marcadores claros indicando onde cada nova página começa no documento final.
- Exames com parâmetros estruturados passam a apresentar os achados/resultados em tabelas, mantendo método, leitura clínica e conclusão em texto.
- A redação continua contextual e profissional, com linguagem acessível para RP sem perder a aparência de laudo clínico institucional.
- Nenhuma migration de banco foi necessária nesta versão.
