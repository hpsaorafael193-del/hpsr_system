# HPSR System 1.0.237 — Vacinação: caderneta maior no preview

## Objetivo
Aumentar exclusivamente a escala visual das cadernetas dentro da área de pré-visualização, sem alterar a estrutura da página, a altura dos cards, a posição do histórico ou regras de vacinação.

## Alterações
- A escala-base do preview passou de 290 px para 400 px nos modelos Adulto, Idoso e Gestante.
- A escala-base do preview infantil passou de 330 px para 440 px.
- O limite mínimo do zoom foi ajustado para 70%.
- O limite máximo do zoom foi ampliado para 125%.
- A área de preview, o histórico no rodapé, o grid da página e o comportamento responsivo foram preservados.
