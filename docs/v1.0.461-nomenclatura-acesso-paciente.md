# HPSR System v1.0.461 — Nomenclatura do acesso do paciente

Alteração exclusivamente textual da tela pública de autenticação do paciente:
- Categoria «Entrar» → «Login».
- Categoria «Criar conta» → «Cadastro».
- Título «Entrar no Portal do Paciente» → «Acesse sua conta».
- Botão «Entrar» → «Acessar Portal».

Os campos, os controles de senha, a distinção paciente/responsável, as rotas e o processamento de autenticação permanecem inalterados. Sem alterações no Supabase.
