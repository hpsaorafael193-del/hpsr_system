# HPSR System 1.0.435 — troca de paciente no planejamento

Correção pontual da aba Obstetra (Gestacional/FIV): o seletor de pacientes não fica mais bloqueado ao editar um planejamento. Trocar de paciente, após confirmação se houver dados no formulário, encerra a edição e limpa as datas, cronograma, observações e prévias locais, sem transferir o planejamento existente para outra pessoa. Um botão explícito permite encerrar a edição e iniciar novo planejamento para o mesmo paciente. A lista e os demais registros do histórico permanecem no Supabase. O seletor só fica indisponível enquanto carrega pacientes ou durante uma operação de salvamento.

Nenhuma mudança de banco, modelo PNG, regra de especialidade ou vínculo médico-paciente.
