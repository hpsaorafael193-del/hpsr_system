# HPSR v1.0.312 — notificações de formulários para a direção

## Alterações

- A Central pessoal de notificações passa a incluir formulários públicos do **Trabalhe Conosco** enquanto estiverem pendentes.
- As notificações são exibidas para **Diretor Técnico / Dev, Diretora, Vice Diretor** e ficam preparadas para **Diretor Clínico**.
- Cada diretor possui leitura independente: marcar a notificação como lida por um usuário não a marca como lida para os demais.
- Novos formulários já registram os metadados de notificação no próprio `payload` de `staff_applications`; nenhuma tabela paralela foi criada.
- A atualização usa o Realtime já existente de `staff_applications`, sem polling adicional.
- Ao selecionar a notificação, o usuário é direcionado para a área **Equipe**, onde os formulários são gerenciados.

## Validação

- `staff_applications` foi confirmado na publicação `supabase_realtime`.
- No momento da atualização não havia formulários com status `Pendente`, evitando notificações retroativas indevidas.
- A verificação sintática dos arquivos alterados não apontou erros de parsing; o typecheck completo continua dependente das dependências do projeto instaladas.

## Banco de dados

Nenhuma migration nova é necessária nesta versão.
