# Versão 1.0.101 — Janela de confirmação de consultas planejadas

- Os horários deixam de ficar restritos ao dia anterior da consulta.
- O portal procura a próxima ocorrência planejada que ainda possua vagas confirmáveis.
- Cada horário aceita confirmação somente enquanto faltarem mais de 24 horas para o atendimento.
- Quando todos os horários da ocorrência atual entram na janela de 24 horas, o portal passa a exibir a próxima ocorrência disponível.
- A API de reserva repete a validação de 24 horas para impedir confirmações fora do prazo.
