# v0.5.43 — Pré-visualização sob demanda na aba Documentos

- A pré-visualização de documentos passou a gerar inicialmente apenas a primeira página.
- As demais páginas são renderizadas sob demanda, conforme o usuário navega no modal.
- O modal exibe indicador de carregamento quando uma página ainda está sendo gerada.
- O comportamento reduz uso de memória e melhora o tempo de abertura em documentos longos.
- O download em PNG continua usando a página atualmente visualizada.
