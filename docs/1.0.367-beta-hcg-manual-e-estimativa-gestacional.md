# v1.0.367 — Beta-hCG manual e estimativa gestacional

## Alteração

- O motor inteligente de **β-hCG (Beta hCG)** deixa de gerar automaticamente o resultado positivo/negativo para o fluxo novo.
- O profissional escolhe diretamente **Negativo** ou **Positivo**.
- O valor quantitativo de **β-hCG (mUI/mL)** passa a ser informado manualmente.
- Quando o resultado é positivo, o sistema calcula uma **faixa gestacional aproximada** usando faixas de referência da gestação inicial.
- A estimativa é apresentada como aproximação, porque as faixas de β-hCG se sobrepõem e um valor isolado não define idade gestacional com precisão.
- Valores positivos baixos/limítrofes não recebem uma idade gestacional falsa; o sistema orienta correlação clínica/controle.
- Resultado negativo com valor quantitativo incompatível recebe aviso de conferência.

## Compatibilidade

- Perfis antigos de `indeterminado` e `seguimento` permanecem reconhecidos internamente para rascunhos/configurações legadas, mas não aparecem como opções do fluxo novo.
- Nenhuma alteração de banco de dados foi necessária.
