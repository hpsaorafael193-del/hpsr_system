# v0.5.69 — Planejamento FIV fiel ao modelo manual

- O planejamento FIV passou a usar como base o modelo manual aprovado, para manter fidelidade visual.
- O sistema agora altera apenas os campos variáveis: nome do paciente, passaporte e datas.
- As datas do FIV passaram a seguir o formato do modelo manual (`dd / mm`).
- Os cinco chips de data são redesenhados nas posições do modelo aprovado.
- O cabeçalho de identificação do paciente é redesenhado somente na área variável, preservando o restante do layout original.
