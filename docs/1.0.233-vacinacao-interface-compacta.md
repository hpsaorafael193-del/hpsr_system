# HPSR System 1.0.233 — Vacinação compacta e sem observações

## Objetivo
Enxugar a interface do módulo Vacinação sobre a base 1.0.232, removendo o campo de observações e reduzindo a altura da pré-visualização sem alterar templates ou estruturas persistentes.

## Arquivos alterados
- `src/app/dashboard/vacinacao/page.tsx`
- `src/lib/vaccination.ts`
- `src/app/api/paciente/registros/route.ts`
- `src/components/layout/DeveloperCreditsModal.tsx`
- `package.json`
- `package-lock.json`

## Alterações
- Removido o campo `Observações` do formulário de nova vacinação.
- Novos registros de vacinação não gravam mais `vaccine.observation`.
- A caderneta deixou de reservar/desenhar observações nos slots, inclusive no modelo infantil.
- Observações antigas permanecem preservadas nos dados legados, mas deixaram de ser exibidas no cartão e no resumo do Portal do Paciente.
- Removida a sincronização de altura da pré-visualização com o painel lateral (`ResizeObserver`).
- Pré-visualização passou a usar altura compacta por grupo: 370 px para Criança e 330 px para os demais modelos.
- Canvas é centralizado dentro da área compacta, sem rolagem própria da prévia.
- Limites de zoom foram ajustados para manter a caderneta dentro da área compacta.
- Histórico de vacinação permanece com rolagem interna e altura máxima reduzida para 260 px.

## Migrations
Nenhuma.

## Compatibilidade
- Nenhum dado antigo foi apagado.
- Nenhuma tabela, coluna, RPC ou política RLS foi modificada.
- Preview e PNG final continuam utilizando o mesmo renderizador.
