# Versão 1.0.154 — Normalização de pontos abertos anteriores

## Objetivo
Garantir que registros de ponto já abertos antes do fluxo atual de presença não permaneçam indefinidamente ativos.

## Alterações
- Criada uma normalização única para todos os pontos que estiverem abertos no momento da migração.
- O encerramento usa o último heartbeat conhecido; em registros legados sem heartbeat, usa a última atualização válida do ponto.
- Segmentos e pausas abertos são encerrados no mesmo horário.
- O total trabalhado é recalculado.
- O perfil relacionado volta para `Fora de serviço`.
- A operação fica registrada em `time_clock_audit`.

## Migração
- `supabase/migrations/20260802_000039_normalize_existing_open_time_clock_entries.sql`

## Compatibilidade
- Não remove registros antigos.
- Não altera pontos já encerrados.
- Após a migração, o usuário precisa iniciar um novo ponto para continuar em serviço.

## Consumo e otimização
- A normalização é executada uma única vez durante a migração.
- Não adiciona polling, heartbeat extra ou novas consultas recorrentes.

## Validações
- Sintaxe e consistência estrutural revisadas estaticamente.
- Build não executado por ausência das dependências instaladas no pacote de trabalho.
