# v1.1.16-test.10 — Editor Integral / Individual

## Objetivo
Centralizar a edição de um planejamento salvo na área **Planejamento previsto por consulta**, deixando o **Histórico de planejamentos** apenas como localizador dos registros.

## Fluxo
1. O histórico lista os planejamentos salvos.
2. `Abrir / editar` carrega o planejamento na área de edição acima.
3. O controle `Integral | Individual` alterna o escopo de edição do mesmo planejamento.
4. O modo Integral edita cronograma, marcos e planejamento previsto.
5. O modo Individual edita uma consulta/etapa por vez, com navegação Anterior / seletor / Próxima.

## Salvamento
- Integral: `Salvar planejamento` / `Salvar alterações` grava os dados estruturados do planejamento e sincroniza as ocorrências.
- Individual: `Salvar consulta/etapa` grava apenas o atendimento atual.
- O campo `Planejamento previsto` é compartilhado: quando salvo no individual, a linha correspondente do integral é atualizada.
- Evolução, exames, resultados, observações compartilháveis e anotações internas permanecem individuais.
- Salvar não libera automaticamente para a paciente.
- Prévia não é requisito para salvar.
- PNG continua sendo materializado apenas quando o usuário clica em `Baixar PNG`.

## Proteção contra perda de alterações
Ao tentar mudar de modo, de consulta/etapa ou abrir outro planejamento com alterações pendentes, o sistema oferece:
- Salvar e continuar;
- Descartar;
- Cancelar.

## Histórico
O Histórico não expande mais um segundo formulário abaixo dele. Ele apenas localiza e abre o planejamento na área oficial de edição.

## Banco de dados
Nenhuma migration e nenhuma alteração de schema nesta rodada.
