# v1.0.282 — Vínculos internos no Prontuário

- Move a gestão de vínculos médico-paciente da Agenda Clínica para **Prontuários → Pendentes**.
- A aba de vínculos é exibida somente para **Diretor Técnico / Dev**.
- Classificação de paciente pendente passa a ser apenas contexto clínico e não altera `schedule_assignments`.
- Remove o antigo botão **Agenda do portal** do prontuário individual.
- Aceitar consulta e criar planejamento deixam de criar vínculo de agenda automaticamente.
- Planejamentos formais não liberam horários sozinhos no Portal; somente um vínculo administrativo explícito permite o roteamento da agenda.
- `set_patient_schedule_link` passa a ser restrita no banco ao Diretor Técnico / Dev e grava metadados de origem administrativa no JSON existente.
- Não cria tabela nova e preserva vínculos existentes para revisão manual.
