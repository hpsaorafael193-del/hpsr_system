# Versão 1.0.180 — Normalização dos campos da RPC de pacientes

## Objetivo
Corrigir a incompatibilidade de tipagem identificada no build da versão 1.0.179.

## Alterações
- Os campos opcionais retornados por `list_patient_registry_staff` agora convertem `null` para `undefined` antes de chamar `normalizePatient`.
- Foram normalizados `passport`, `name`, `age`, `blood_type`, `city_phone` e `email`.
- Nenhuma regra de negócio, consulta ou estrutura de banco foi alterada.

## Migrações
- Nenhuma migração nova.
- Continua necessária a migração da versão 1.0.178: `supabase/migrations/20260803_000043_stabilize_patient_registry_and_time_clock.sql`.

## Validação
- Revisão estática da tipagem corrigida.
- O build completo não foi executado neste ambiente por ausência das dependências instaladas.
