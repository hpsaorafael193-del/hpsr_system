# 1.1.16-test.146 — colar imagens como anexos

- Área focável “Colar imagem como anexo” no formulário e no editor de anexos dos exames. Clique na área e use Ctrl+V/⌘V depois de “Copiar imagem” no navegador ou copiar uma imagem/captura.
- Usa primeiro os arquivos de imagem da área de transferência, sem duplicar a imagem representada também no HTML. Se houver apenas uma imagem no HTML, tenta importar seus bytes; apresenta uma mensagem se a origem bloquear a leitura. Não mantém dependência de um endereço remoto para exibir o anexo posteriormente.
- As imagens coladas seguem o mesmo fluxo de imagens selecionadas em arquivo: possibilidade de substituir o anexo atual ou adicionar nova página, visualização, remoção e snapshot existentes.
- Não intercepta colagem nos campos de texto ou no editor do laudo. A colagem deve ocorrer na área indicada de anexos. O seletor de arquivos continua disponível.
- Na aba Documentos não há atualmente um fluxo de anexos; ela não foi alterada nesta correção.
- Sem mudanças de banco ou publicação automática; versão pública 1.1.16 mantida.

Validação: testes de arquivo no clipboard, fallback de arquivos, prioridade sobre HTML, ausência de imagem, importação de imagem web, origem inválida, resposta não-imagem e falha de CORS; integração das duas áreas com o fluxo de anexos. Build de produção e auditoria de release. Não houve teste interativo de clipboard em navegador nem escrita no banco.
