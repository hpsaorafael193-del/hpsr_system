# v1.1.16-test.123 — Remoção de acesso local

Correção da versão atual, separada da 1.2. Base completa test.122.

Removido o caminho de login Dev local sem Supabase. O formulário não cria sessão local, o botão de login fica indisponível sem configuração e o painel não aceita mais uma sessão legada, mesmo marcada como administradora. O módulo local-auth foi excluído. Chaves antigas são apenas apagadas, nunca utilizadas para conceder acesso.

O provedor de perfil usa um estado sem identidade autenticada e sem privilégios quando não há sessão/configuração/perfil. Atualizar dados sem Supabase retorna falha em vez de anunciar um salvamento local. O login real com conta aprovada no Supabase e a aprovação de cadastro profissional foram preservados.
