# v1.1.16-test.102

Base: v1.1.16-test.101.

O portal agora abre registros antigos de vacinação usando o renderizador da caderneta oficial, reconstruindo o modelo somente com aplicações já liberadas do passaporte autorizado. Cadernetas publicadas com snapshot continuam sendo a versão principal, sem duplicação por dose. A lista agrupa aplicações liberadas por modelo. Registros sem identificação do modelo exibem erro de correção pela equipe, em vez de uma página textual simulando a caderneta.

Nenhum PNG é salvo; prévia e download usam o mesmo renderizador. Permissões e liberação médica permanecem obrigatórias. Não requer migração adicional.

Removidos os atalhos que exibiam HTML avulso no portal ou baixavam uma ficha HTML em vez da folha. O fallback antigo do visualizador de prontuários também usa o renderizador institucional. Exames/documentos, vacinação e planejamentos usam visualização virtual com os mesmos dados do download, sem persistir imagens geradas.
