# v1.0.292 — Discord do desenvolvedor sem exposição de ID

- A função de contato do desenvolvedor permanece no mesmo modal **Sobre o sistema**, usado tanto no dashboard médico quanto nas áreas públicas.
- O Discord ID deixou de existir nos componentes client-side e não é exibido em texto, HTML ou JavaScript do navegador.
- Removido o link direto ao perfil, pois o próprio endereço revelaria o identificador.
- O contato passa a exibir somente o usuário público `@lluidhy`.
- Adicionadas as ações **Copiar usuário** e **Abrir Discord**.
- O identificador privado não é persistido no código-fonte desta versão. Caso alguma integração server-side futura precise dele, deve ser armazenado apenas em variável de ambiente privada, sem prefixo `NEXT_PUBLIC_`.
- Nenhuma alteração de banco de dados.
