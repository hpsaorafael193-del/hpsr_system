# HPSR System 1.0.430 — Planejamento Gestacional/FIV flexível

- Preserva os quatro templates visuais aprovados (Gestacional integral/individual e FIV integral/individual).
- As semanas/marcos do RP são apenas rótulos e não entram no cálculo de calendário.
- Gestacional sugere quartas-feiras e FIV sugere terças-feiras entre a data inicial e a data final de referência.
- A sugestão não cria registros: o médico precisa conferir e confirmar o cronograma.
- Se o período não produzir a quantidade esperada pelo modelo (8 Gestacional / 5 FIV), o sistema apenas avisa e aguarda ajuste das datas.
- Planejamento integral e individual usam a mesma fonte de dados para o texto previsto.
- Evolução/observações e conduta/retorno permanecem separadas do planejamento previsto.
- Liberação integral e individual são independentes, com snapshot da versão liberada.
- O planejamento não cria vagas nem agendamentos; continua usando apenas o fluxo existente do Agendamento.
- Vínculo médico-paciente da especialidade é obrigatório antes da criação do planejamento.
