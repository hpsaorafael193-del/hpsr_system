# HPSR 1.0.273 — Histórico de formulários de candidatos

- Adicionado acesso ao Histórico diretamente no modal de Formulários pendentes.
- A ação superior "Candidatos" foi renomeada para "Histórico de formulários".
- O histórico reutiliza todos os registros persistidos em `staff_applications` e permite abrir novamente a análise.
- A análise ganhou edição opcional de dados administrativos/cadastrais do formulário.
- Respostas do questionário permanecem somente leitura, preservando o conteúdo originalmente enviado pelo candidato.
- Nenhuma migration necessária.
