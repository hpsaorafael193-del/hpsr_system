# v0.5.33 — Nome do paciente no arquivo PNG

- O nome do paciente agora passa a compor o nome do arquivo ao baixar a página do exame em PNG.
- O formato de saída agora segue o padrão: nome-do-exame_nome-do-paciente_pagina-X.png.
- A alteração não muda o conteúdo visual do laudo, apenas o nome final do arquivo exportado.
