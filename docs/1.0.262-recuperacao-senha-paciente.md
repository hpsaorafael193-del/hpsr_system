# HPSR 1.0.262 — recuperação de senha do paciente

- Corrige o retorno de recuperação para aguardar exclusivamente o evento `PASSWORD_RECOVERY` do Supabase.
- Remove a troca manual concorrente de `code`/tokens na página de redefinição, evitando consumo duplo do código de recuperação.
- Links iniciados pelo Portal carregam `origem=paciente`; links da equipe carregam `origem=equipe`.
- Links antigos sem origem passam a usar o Portal do Paciente como destino seguro padrão.
- `Solicitar novo link` de paciente volta para `/paciente`, não para `/login`.
- Nenhuma migration.
