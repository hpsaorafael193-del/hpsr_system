# Versão 1.0.151 — Correção de pacientes pendentes no Prontuário

## Objetivo
Garantir que falhas ao consultar `patient_portal_access` não façam pacientes pendentes serem exibidos incorretamente como classificados.

## Arquivos alterados
- `src/app/dashboard/prontuarios/page.tsx`
- `package.json`
- `package-lock.json`
- `src/components/layout/DeveloperCreditsModal.tsx`

## Estruturas reutilizadas
- Consulta existente de `patient_portal_access`.
- Estado já carregado do Prontuário.

## Alteração
A leitura de `patient_portal_access` passou a ser obrigatória para concluir a sincronização dos pacientes. Em caso de erro nessa consulta, o sistema mantém o último estado válido em vez de classificar os pacientes por padrão.

## Migrações
Nenhuma.

## Compatibilidade
Registros antigos e fluxos de cadastro foram preservados.

## Otimização
Nenhuma nova consulta foi adicionada. A correção reutiliza a consulta já existente.

## Validações
- Revisão estática do fluxo de carregamento.
- Verificação de diferenças e estrutura do pacote.
- Build não executado por ausência das dependências instaladas no pacote de trabalho.
