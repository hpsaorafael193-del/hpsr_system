# v1.0.358 — Recusa de solicitações e Observações do Prontuário

## Solicitações clínicas
- Corrige `hpsr_decline_clinical_request` para usar `hpsr_doctor_has_specialty`, a mesma regra de elegibilidade usada no aceite.
- Consultas comuns continuam levando em conta a capacidade clínica disponível dos demais profissionais.
- Exames não usam capacidade de consulta para decidir se ainda existem profissionais elegíveis.
- Solicitações direcionadas a um médico específico são encerradas quando esse médico recusa.
- A recusa individual apenas adiciona o profissional a `declinedBy` quando ainda há outro candidato válido.
- O pedido só muda para `Recusada` quando não resta candidato elegível.
