# v0.5.70 — Planejamento FIV no modelo do sistema

- O planejamento FIV voltou a usar o modelo visual original do sistema (`ivf.webp`).
- Foi removida a tentativa de basear a exportação no planejamento manual externo.
- Nome do paciente e passaporte voltaram a ser desenhados apenas como valores sobre o modelo do sistema, sem alterar a tipografia do template.
- As datas continuam sendo geradas automaticamente, posicionadas nos cinco campos do modelo do sistema.
