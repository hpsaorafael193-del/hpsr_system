# v1.0.280 — Gestão interna de vínculos médico-paciente

- Diretor Técnico/Dev passa a ter uma área própria na Agenda Clínica para revisar vínculos paciente → médico → especialidade.
- É possível criar, editar e remover vínculos de agenda para qualquer médico, sem usar o perfil do operador como médico responsável.
- A tela consolida vínculos explícitos e acompanhamentos formais para conferência.
- Quando existem vínculos explícitos, eles passam a ser a referência de roteamento dos horários no Portal do Paciente; planos formais compatíveis enriquecem o mesmo vínculo e planos divergentes não ressurgem por trás de uma correção administrativa.
- Nenhuma nova tabela ou fonte persistente foi criada.
