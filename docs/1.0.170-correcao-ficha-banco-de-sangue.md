# Versão 1.0.170 — Correções da ficha do Banco de Sangue

## Objetivo
Corrigir obrigatoriedades, seleção do médico responsável e exibição de campos condicionais na ficha de triagem do Banco de Sangue.

## Arquivos alterados
- `src/app/dashboard/banco-de-sangue/page.tsx`
- `src/components/layout/DeveloperCreditsModal.tsx`
- `package.json`
- `package-lock.json`

## Estruturas reutilizadas
- Tabela `profiles` para listar profissionais aprovados.
- Validador compartilhado `isClinicalProfessional`.
- Estrutura existente de `blood_donations` e campo `payload`.

## Alterações realizadas
- Peso e telefone passaram a ser opcionais.
- Médico responsável passou a ser selecionado entre profissionais clínicos aprovados.
- Campos de condição crônica e medicamento aparecem apenas quando a resposta é `Sim`.
- Campo de data da transfusão aparece apenas quando houve transfusão.
- Detalhes de viagem aparecem apenas quando houve viagem de risco.
- Pergunta sobre reação anterior aparece apenas para quem já doou sangue.
- Respostas dependentes são limpas ao alterar a resposta principal para `Não` ou `N/A`.

## Banco e compatibilidade
- Nenhuma migração necessária.
- Registros antigos preservados.
- Uma consulta direcionada a `profiles`, somente com colunas necessárias, executada em paralelo ao carregamento das triagens.

## Validações
- Revisão estática dos campos e condições alterados.
- Arquivos JSON validados.
- Build completo não executado porque o pacote não contém as dependências instaladas.
