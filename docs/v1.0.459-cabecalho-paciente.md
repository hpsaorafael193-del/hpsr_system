# HPSR System v1.0.459 — Seletor de perfis no cabeçalho

- O botão Paciente logado do cabeçalho abre o seletor vertical de prontuários, vínculos pendentes e a opção Cadastrar filho ou filha.
- A central de notificações foi movida para o cabeçalho, à esquerda do botão Paciente logado.
- Removidos o botão Perfil flutuante inferior e o sino/atalho de perfil duplicados no conteúdo do Portal.
- Os eventos de interface conectam cabeçalho e Portal, sem alterar APIs, permissões, banco ou lógica dos agendamentos.
- A seleção continua validada pelas informações de pacientes autorizados da sessão, sem liberar vínculos pendentes.
