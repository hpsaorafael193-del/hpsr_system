# v1.0.363 — Correção de build do Prontuário e dependência do ESLint

## Prontuário

- Corrigida a tipagem de `ExamsTab.onDelete`: a ação de exclusão é opcional, pois usuários sem permissão administrativa não recebem callback de exclusão.
- O callback agora aceita retorno síncrono ou assíncrono (`void | Promise<void>`), compatível com `deleteClinicalRecord`.
- `EventCard` e `FilteredEventsTab` foram alinhados à mesma assinatura.
- A chamada do callback usa `void onDelete(event)` para o handler de clique.

Isso corrige o erro de build:

`Type '((event: TimelineEvent) => Promise<void>) | undefined' is not assignable to type '(event: TimelineEvent) => void'.`

## ESLint / pnpm

O projeto já mantém `es-to-primitive` 1.3.0 como dependência direta de desenvolvimento, override do pnpm e `public-hoist-pattern` no `.npmrc`. O erro `Cannot find module es-to-primitive/es2015` indica uma instalação/linkagem antiga ou incompleta do `node_modules`.

Após atualizar os arquivos da versão, reconstruir as dependências no Windows:

```powershell
Remove-Item -Recurse -Force node_modules
pnpm install --force
pnpm run build
```

Se a pasta já foi removida, basta executar `pnpm install --force` e depois o build.

## Banco

Nenhuma migration nova nesta versão. As proteções de prontuário da v1.0.362 permanecem inalteradas.
