# Versão 1.0.176 — Atualização do histórico do Banco de Sangue

## Objetivo
Corrigir a interpretação da opção de atualização no Banco de Sangue, mantendo a atualização na área geral do histórico em vez de disponibilizá-la em cada ficha.

## Arquivos alterados
- `src/app/dashboard/banco-de-sangue/page.tsx`
- `src/components/layout/DeveloperCreditsModal.tsx`
- `package.json`
- `package-lock.json`

## Alterações realizadas
- Removido o botão individual `Atualizar` de cada ficha.
- Removido o fluxo de edição de uma ficha já registrada.
- Adicionado um único botão `Atualizar histórico` no cabeçalho da área de histórico.
- O botão recarrega do Supabase a lista completa de fichas, ordenada pela data mais recente.
- Adicionado estado visual de carregamento para impedir atualizações simultâneas.
- A ficha selecionada é mantida somente quando ainda existe após a atualização.

## Estruturas reutilizadas
- Consulta existente à tabela `blood_donations`.
- Lista e filtro existentes do histórico.
- Componente de alerta já utilizado pelo módulo.

## Migrações
- Nenhuma.

## Otimização
- A consulta é executada somente ao abrir a página ou ao clicar no botão.
- Não foi adicionado polling nem listener recorrente.
- Apenas as colunas necessárias continuam sendo consultadas.

## Validações
- Revisão estática do arquivo alterado.
- Conferência da remoção do fluxo de edição individual.
- Build completo não executado por ausência das dependências instaladas no pacote de trabalho.
