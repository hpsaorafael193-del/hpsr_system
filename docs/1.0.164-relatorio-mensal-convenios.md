# Versão 1.0.164 — Relatório mensal de convênios

## Objetivo
Adicionar na aba Convênios um relatório mensal com totais, tipos de plano, valores, titulares e dependentes.

## Arquivos alterados
- `src/app/dashboard/convenios/page.tsx`
- `package.json`
- `package-lock.json`

## Estruturas reutilizadas
- Dados já carregados de `financial_plan_entries`.
- Catálogo existente de planos e valores.
- Modal e componentes visuais existentes da aba.

## Migrações
Nenhuma.

## Compatibilidade
Registros antigos são preservados. O relatório usa a data de criação financeira do plano e, como fallback, a data de ativação.

## Otimizações
Nenhuma consulta adicional ao Supabase. A lista completa carregada pela própria página é reutilizada e agregada no navegador somente quando o relatório é exibido.

## Validações
- Estrutura TSX revisada.
- Nenhuma alteração destrutiva no banco.
- Build completo depende da instalação das dependências do projeto.
