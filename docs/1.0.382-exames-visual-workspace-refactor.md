# HPSR System 1.0.382 — Refatoração visual de Exames

- Reorganiza o estado inicial da página em grid: informações clínicas compactas + catálogo ocupando o espaço restante.
- Remove o grande container externo que deixava áreas vazias sem função.
- Depois da seleção do exame, informações e catálogo deixam de competir com o editor; o contexto do paciente/médico fica em uma barra resumida.
- Adiciona ação explícita para editar/concluir informações sem reabrir blocos permanentemente.
- Integra anexos ao próprio workspace do editor e remove a seção independente de anexos acima do editor.
- O painel do modelo passa a aproveitar colunas responsivas para reduzir altura sem esconder campos.
- Ajusta dimensões e densidade do editor para seguir a linguagem visual do Dashboard principal.
- Nenhuma migration ou alteração de banco nesta versão.
