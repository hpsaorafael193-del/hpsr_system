# HPSR System 1.0.229 — Vacinação: lote automático, ajuste de passaporte e carimbo

## Objetivo
Aplicar ajustes localizados no módulo de Vacinação sobre a base 1.0.228, sem alterar banco, regras clínicas centrais ou estruturas persistentes.

## Arquivos alterados
- `src/app/dashboard/vacinacao/page.tsx`
- `src/lib/vaccination.ts`
- `src/components/layout/DeveloperCreditsModal.tsx`
- `package.json`
- `package-lock.json`

## Estruturas reaproveitadas
- Persistência em `clinical_records` com `record_type = "Vacina"`
- Renderização da caderneta já existente em Canvas
- Fluxo atual de exportação PNG e histórico vacinal

## Alterações realizadas
- O lote da vacina passou a ser gerado automaticamente pelo sistema em formato alfanumérico (`VX-XXXXXXX`).
- O campo de lote passou a exibir o código gerado automaticamente e permite apenas regenerar outro código via botão, sem digitação manual.
- O salvamento garante lote automático mesmo se o valor estiver vazio por qualquer motivo.
- Ajustadas as coordenadas do passaporte na renderização das cadernetas para melhor alinhamento visual.
- O carimbo foi ampliado de forma moderada na renderização da caderneta.
- Versão da entrega atualizada para `1.0.229` em todos os locais relevantes.

## Migrations
- Nenhuma.

## Compatibilidade
- Mantida compatibilidade com registros vacinais antigos já salvos.
- Não houve mudança de schema, RPC, RLS ou tabelas.
- Preview e PNG final continuam usando o mesmo renderizador.
