# Versão 1.0.187 — Solicitações de médicos ativos e histórico

## Objetivo
Separar corretamente cadastros novos e profissionais ativos dos registros de médicos desativados, removidos ou recusados.

## Alterações
- A lista principal de Gerenciar Médico agora exibe apenas:
  - novos cadastros pendentes;
  - cadastros aprovados cujo perfil continua ativo.
- Registros recusados, desativados, removidos, desligados ou sem vínculo ativo passam automaticamente para a visualização de histórico.
- Perfis desativados não são mais convertidos em novas solicitações pendentes.
- Os contadores consideram somente a lista principal atual.
- O histórico informa o motivo pelo qual o registro foi arquivado.
- Ao desligar um profissional, as solicitações relacionadas são localizadas por `auth_user_id` e também por passaporte, preservando compatibilidade com registros antigos.
- Registros arquivados automaticamente por desligamento/recusa não podem ser restaurados indevidamente para a lista ativa.

## Banco de dados
- Nenhuma migração nova.
- Nenhuma consulta recorrente nova.
- A carga continua ocorrendo no mesmo fluxo já existente da tela de equipe.

## Validação
- Revisão estática da filtragem e do fluxo de desligamento.
- Build completo não executado no ambiente por ausência das dependências instaladas no pacote limpo.
