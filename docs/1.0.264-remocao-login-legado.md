# HPSR 1.0.264 — remoção do login legado

- A rota `/login` não renderiza mais a antiga página de login/cadastro da equipe.
- Acessos antigos a `/login` redirecionam para a página inicial com o modal atual de **Acesso Médico** aberto.
- A redefinição de senha da equipe retorna ao acesso médico atual (`/?acesso=medico`), nunca ao login legado.
- O Portal do Paciente continua retornando para `/paciente` após recuperação.
- Nenhuma migration ou mudança de schema.
