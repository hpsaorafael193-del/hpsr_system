# v0.5.72 — Identificação na mesma linha dos planejamentos

- Ajustado o preenchimento da identificação para o formato ideal:
  - `NOME: Nome do paciente`
  - `PASSAPORTE: passaporte do paciente`
- No planejamento FIV, os dois campos são renderizados explicitamente na mesma linha dos rótulos, preservando o restante do template.
- O mesmo padrão foi mantido nos planejamentos pré-natais para consistência visual.
