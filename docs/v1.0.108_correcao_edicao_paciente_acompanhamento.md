# Versão 1.0.108 — Correção ao editar paciente

- Normalizado o campo `follow_up` antes de carregar e salvar pacientes.
- O banco aceita somente `Rotina`, `Clínico` e `Especializado`.
- Rótulos antigos derivados de outros registros deixam de ser enviados ao `patient_registry`.
- A edição do paciente não é mais bloqueada pela constraint `patient_registry_follow_up_valid`.
