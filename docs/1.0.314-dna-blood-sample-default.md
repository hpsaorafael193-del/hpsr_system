# HPSR v1.0.314 — Teste de DNA com amostra sanguínea por padrão

- O Teste de DNA passa a usar **Sangue periférico** como tipo de amostra padrão.
- A opção de sangue foi colocada como primeira opção do campo de amostra.
- Referências e perfis prontos do laudo de DNA foram alinhados para sangue, evitando que o resultado volte a indicar swab bucal.
- Swab bucal e Outro continuam disponíveis como alternativas manuais.
- Nenhuma alteração no Supabase foi necessária.
