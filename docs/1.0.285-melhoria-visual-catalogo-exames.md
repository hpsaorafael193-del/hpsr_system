# HPSR v1.0.285 — Melhoria visual do catálogo de exames

## Objetivo
Modernizar a seleção de exames sem alterar o fluxo clínico, os modelos existentes ou a fonte de dados do módulo.

## Alterações
- busca do catálogo recebeu maior destaque e ação rápida para limpar o termo;
- categorias passaram de um select tradicional para filtros visuais horizontais;
- cada categoria exibe a quantidade de exames disponíveis;
- catálogo passou de grade comprimida em duas colunas para lista compacta de largura inteira;
- cartões exibem categoria, nome e descrição curta, com estado selecionado mais evidente;
- contador de resultados e estado vazio com ação para limpar filtros;
- mantidos `intelligentExamModels`, `catalogCategory`, `examSearch` e `applyModelFor` como estruturas existentes, sem criar fluxo ou fonte paralela.

## Compatibilidade
Nenhuma alteração de banco, migration, persistência clínica, renderização do laudo ou vínculo com consultas.
