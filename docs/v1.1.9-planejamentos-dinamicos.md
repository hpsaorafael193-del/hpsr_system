# HPSR System v1.1.9 — Planejamentos Gestacional e FIV dinâmicos

## Escopo

- A prévia médica continua utilizando os PNGs dos modelos oficiais **apenas em memória**. Não são enviados PNGs permanentes ao salvar ou atualizar planos e consultas.
- Os dados estruturados continuam nas tabelas `clinical_followup_plans` e `clinical_followup_occurrences`, já existentes. Não é necessária uma migration nesta versão.
- Quando o médico libera o planejamento integral ou uma consulta, o snapshot explicitamente publicado alimenta a visualização dinâmica do Portal. Uma nova edição atualiza somente o conteúdo previamente liberado; nenhuma liberação de consulta concede automaticamente acesso ao plano integral ou a outras consultas.
- Cada revisão de um conteúdo anteriormente liberado fica arquivada em `planning_document_versions` ou `individual_document_versions` (JSONB), incluindo o snapshot anterior. Os caminhos de PNG antigos permanecem no histórico sem exclusão.
- O Portal renderiza os dados diretamente em HTML. Uma aba autenticada de impressão permite Salvar como PDF pelo navegador; o PNG oficial é gerado em memória apenas ao selecionar **Baixar PNG**.
- O Portal recarrega ao voltar à página e faz uma atualização leve a cada 120 segundos enquanto a aba está visível, aproveitando o mecanismo já existente.
- `medical_observation_text` e `followup_report.private_draft` não são enviados nem ao renderizador imprimível nem ao JSON de publicação para o Portal.
- Cadernetas, documentos de terceiros, arquivos de exames e a lógica de Agendamento não mudam nesta versão.

## Compatibilidade

Os registros de publicação com `planning_released_document_path` ou `individual_released_document_path` antigos continuam disponíveis como PNG através das rotas originais. No próximo salvamento da versão corrente, a médica passa a trabalhar com o documento dinâmico; o PNG anterior é preservado no histórico. O Portal exige sessão válida e correspondência exata entre paciente, planejamento e liberação antes de oferecer PDF ou PNG dinâmico.

## Verificações

Executar no diretório `hpsr_system/`: `node tests/obstetric-v119-dynamic.mjs`, `node tests/portal-audit.mjs` e os testes existentes em `tests/`. Para o build completo, usar o Node 24 e instalar as dependências do projeto (`pnpm install` e `pnpm run build`).
