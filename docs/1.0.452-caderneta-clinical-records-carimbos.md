# HPSR System v1.0.452 — correção da persistência e alinhamento

- Aplicações permanecem em `clinical_records` com `record_type = Vacina`.
- Caderneta como documento do **mesmo prontuário**: `record_type = CadernetaVacinal` e metadados no JSONB `payload`; campos existentes `is_confidential`, `released_at`, `released_by` controlam acesso ao Portal.
