# HPSR System 1.0.238 — Ajuste visual da caderneta infantil

## Objetivo
Corrigir exclusivamente o posicionamento dos dados e o aproveitamento dos slots no modelo infantil, com base no PNG real exportado na versão 1.0.237.

## Alterações
- Recalibrados Criança, Passaporte, Data de nascimento e Responsáveis para permanecerem na mesma linha visual dos respectivos rótulos do template infantil.
- Passaporte passa a iniciar somente após o fim do rótulo impresso.
- Data de nascimento passa a iniciar após o rótulo completo, sem sobreposição.
- Responsável deixa de cair sobre a marca São Rafael.
- Área textual das aplicações infantis ampliada e reposicionada.
- Carimbo dos slots infantis ampliado e centralizado em área própria à direita.
- Slots infantis curtos e regulares continuam com configurações independentes.

## Estruturas reaproveitadas
- Template infantil PNG existente.
- `VaccinationIdentityLayout`, `VaccinationSlotContentLayout` e `VaccinationStampLayout`.
- Renderizador Canvas único compartilhado entre prévia e PNG final.

## Migrations
Nenhuma.

## Compatibilidade
Nenhuma alteração de schema, persistência, RLS, RPC ou dados antigos.

## Validação
Revisão estática das coordenadas contra o template e o PNG real exportado fornecido para diagnóstico. Build somente pode ser declarado aprovado se `npm run build` concluir no ambiente.
