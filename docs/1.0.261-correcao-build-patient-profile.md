# HPSR 1.0.261 — Correção de tipagem do perfil do paciente

- Corrige a incompatibilidade de retorno entre `checkSession` (`Promise<boolean>`) e a callback `onSaved` do `PatientProfilePanel` (`void | Promise<void>`).
- A callback agora aguarda `checkSession()` sem propagar o valor booleano, preservando o comportamento existente.
- Nenhuma regra de negócio, schema, migration ou fluxo do Portal foi alterado.
