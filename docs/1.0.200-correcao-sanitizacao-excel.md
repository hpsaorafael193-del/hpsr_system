# Versão 1.0.200 — Correção da sanitização do relatório Excel

## Correção
- Restaurada a função `sanitizeXmlText` utilizada pelo gerador de planilhas.
- Adicionada a função `xmlEscape`, responsável por escapar caracteres reservados do XML.
- Caracteres de controle inválidos para XML são removidos antes da geração.
- Textos são limitados ao máximo suportado por uma célula do Excel.

## Resultado
- Corrige o erro em tempo de execução `sanitizeXmlText is not defined`.
- Evita que caracteres inválidos presentes nos dados corrompam o pacote XLSX.
- Mantém a compactação e validação com JSZip introduzidas na versão anterior.

## Banco de dados
- Nenhuma migração.
- Nenhuma consulta nova ao Supabase.

## Validação
- Revisão estática do gerador de XLSX e das referências às funções de sanitização.
- Build completo não executado neste ambiente por ausência das dependências instaladas no pacote limpo.
