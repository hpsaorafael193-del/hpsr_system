# v1.0.281 — Vínculo manual de exame com consulta

- Mantém `clinical_records` como fonte única dos exames.
- Reutiliza `payload.appointmentId` para relacionar o exame original a uma consulta, sem duplicação de registro.
- Em Exames, o médico pode escolher manualmente uma consulta do paciente mesmo quando ela não está em atendimento.
- O modo automático continua vinculando à consulta em atendimento do mesmo médico quando disponível.
- Também é possível salvar explicitamente como exame avulso.
- A lista manual é limitada às consultas elegíveis do paciente e mostra data, especialidade, médico e status para reduzir vínculos incorretos.
